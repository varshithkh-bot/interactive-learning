# Interactive Learning

Hands-on physics and engineering simulations. Each lesson is a single self-contained HTML file that explains itself at four levels: Class 10, Class 12, Engineering, and M.Tech & professional.

**Live site:** https://varshithkh-bot.github.io/interactive-learning/

| Lesson | File |
| --- | --- |
| The RC circuit, live | [rc-circuit-explorer.html](rc-circuit-explorer.html) |

## Working on it

- Open any `.html` file directly in a browser to preview it. There is no build step.
- Pushing to `main` redeploys the site on GitHub Pages, usually within a minute.
- To add a lesson, add its `.html` file and a card for it in `index.html`.
